# docs/ui/contracts — UI contract pack (v2)

The contract the web UI and its BFF build against. The mock implements it exactly, and so must the real BFF. See [../ALIGNMENT.md](../ALIGNMENT.md) for ownership and [../BUILD-SPEC.md](../BUILD-SPEC.md) for how to use it.

| Path | What |
|---|---|
| `experience-api.openapi.yaml` | OpenAPI 3.1: 121 paths, 136 operations, 86 component schemas (the three case-document operations are EHF document intelligence). `x-upstream` (relayed EHF route), `x-action` (EHF platform action), `x-poll`, `x-owner`, `x-status`, `x-screens`, `x-mock-only`. Generated by `gen/openapi_v2.py`; fixtures by `gen/fixtures_v2.py`. |
| `upstream/ehf-contracts.schema.json` | 198 schemas exported from `@ehf/contracts` (zod 4.6.5). **Never edit** — regenerate. |
| `upstream/control-ui-views.schema.json` | 61 view models of the replaced control-ui BFF (frozen from `types.ts`; cloud-vendor values removed by hand once the source was deleted, see `x-source.amended`). History after cutover. |
| `proposed/*.schema.json` | 5 A2UI presentation schemas with no upstream owner yet. |
| `fixtures/` | `personas` (EHF roles → actions), `fincrime.catalog` (from kyc `ehf-catalog.json`), `ehf.kyb-1042` (EHF-shaped store, 5 states), `scenario.kyb-1042` (FinCrime read models + transitions), `platform` (control-ui view seeds), `records.kyb-1042` (kyc Records). All synthetic. |
| `SOURCES.lock.json` | sha256 pins for 258 upstream files (kyc 0.3.0, ehfconcept `249ab42`) plus the zod-export digest. |
| `redocly.yaml` | Lint config (recommended, minus one rule that only fires inside upstream-owned schemas). |
| `tools/check_sources.py` | Drift report against the lock; `--update` re-pins after review. Exit 1 on drift. |
| `tools/export_ehf_contracts.mts` | Re-export `upstream/ehf-contracts.schema.json` from an ehfconcept checkout. |
| `tools/export_control_ui_views.mjs` | Re-freeze `upstream/control-ui-views.schema.json` from control-ui `types.ts`. |
| `tools/validate_contracts.py` | OpenAPI conventions, upstream route check (`--ehf-root`), every fixture against its owner's schema (1,022 checks). |
| `tools/gen_appendices.py` | Regenerates BUILD-SPEC appendices A–F; fails on unknown screen ids. |

```bash
# from the kyc repo root, with ehfconcept checked out beside it
pip install jsonschema referencing pyyaml
python3 docs/ui/contracts/tools/check_sources.py                       # drift?
node --experimental-strip-types docs/ui/contracts/tools/export_ehf_contracts.mts ../ehfconcept
python3 docs/ui/contracts/tools/validate_contracts.py --ehf-root ../ehfconcept
python3 docs/ui/contracts/tools/gen_appendices.py
REDOCLY_TELEMETRY=off npx @redocly/cli lint docs/ui/contracts/experience-api.openapi.yaml --config docs/ui/contracts/redocly.yaml
```

**Change protocol:** change the generator or the upstream source, never the generated file. Re-export, validate, regenerate appendices, then `check_sources.py --update` and commit the lock with the reason.
