# Connector marks

These assets identify third-party source systems in the connection catalog. They are
served locally; configuring or browsing a connector does not request remote images.

- `databricks.svg`, `postgresql.svg`, `salesforce.svg`, `snowflake.svg`: [Simple Icons 13.21.0](https://github.com/simple-icons/simple-icons/tree/13.21.0/icons), CC0. Brand colors are applied to the original paths. See `LICENSE.simple-icons.txt`.
- `sqlserver.svg`: [Devicon Microsoft SQL Server original](https://github.com/devicons/devicon/blob/master/icons/microsoftsqlserver/microsoftsqlserver-original.svg), MIT. See `LICENSE.devicon.txt`.
- `fabric.svg`: [Fabric application logo](https://content.powerapps.com/resource/powerbiwfe/images/spinner-Fabric-logo.3734b9f10a69c32b36b6.svg), referenced by the [official Fabric application](https://app.fabric.microsoft.com/).
- `fenergo.svg`: [Fenergo favicon](https://cdn.prod.website-files.com/649bda80099ef51a3cc09f8a/64a69c2608bc7f2ce55c697f_favicon.svg), referenced by the [official Fenergo website](https://www.fenergo.com/).

Vendor marks identify their respective products and remain their owners' trademarks.
Other entries use a text fallback. REST is a protocol category and uses an API text mark.
Visible vendor names accompany every mark; decorative images have empty alternative text.
